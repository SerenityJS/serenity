# Data

Vanilla data for the Minecraft version SerenityJS supports: blocks, items, the creative inventory and recipes, among others.

## Regenerating

`tools/generate.mjs` refreshes the block, item, creative inventory and recipe files in `src/json` from [Dragonfly](https://github.com/df-mc/dragonfly)'s vanilla data. Point `DRAGONFLY_COMMIT` at the Dragonfly commit that supports the new version, then run it from this folder:

```
node tools/generate.mjs
```

It downloads the files from GitHub; pass the path of a Dragonfly checkout to read them from there instead. The script's header describes what it keeps from the current files.

The other files (`biome_types.json`, `block_drops.json`, `entity_types.json`, `tool_types.json` and the files in `src/bin`) are not generated by it.
